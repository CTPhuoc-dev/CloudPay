Feedback and Contributions

During my participation in the First Cloud AI Journey program, I had the opportunity to learn about cloud computing, explore AWS services, and complete a practical project.

This was a meaningful experience that helped me expand my technical knowledge, improve my self-learning skills, and develop a clearer career direction in Cloud Computing.

General Evaluation

1. Learning and Working Environment

The program provided a friendly and open environment that encouraged participants to explore new knowledge independently.

During the internship, I was able to communicate with other participants, review learning materials, and receive guidance whenever I encountered difficulties. This helped me become more confident when approaching technologies that I had not used before.

In addition, activities organized by FCAJ and the AWS Study Group provided opportunities for participants to connect, share experiences, and expand their professional networks within the technology community.

2. Support from Mentors and Organizers

The mentors and organizers provided learning materials, suggested a clear roadmap, and supported participants in resolving issues that occurred during project development.

I appreciated that participants were encouraged to research and experiment independently before receiving direct guidance. This approach helped me improve my ability to search for information, analyze errors, and select appropriate solutions.

However, I would appreciate more short progress review sessions during each project phase so that participants could receive feedback earlier.

3. Relevance to My Major

The program content was relevant to my Information Technology major.

Topics such as AWS, website deployment, API development, user authentication, and system monitoring are directly related to programming, computer networking, cybersecurity, and software development.

Through the CloudPay – Payment System on AWS project, I had the opportunity to combine knowledge from different subjects and apply it to a basic cloud architecture.

4. Opportunities for Learning and Skill Development

During the internship, I learned more about:

  • Cloud computing and system architecture on AWS.
  • Frontend deployment using Amazon S3 and CloudFront.
  • User management and authentication using Amazon Cognito.
  • API development using Amazon API Gateway and AWS Lambda.
  • Log monitoring using Amazon CloudWatch.
  • Technical documentation using Markdown.
  • Internship report website development using Hugo.
  • Documentation research and troubleshooting during implementation.
  • Time and task management.

The program helped me develop not only my technical knowledge but also my self-learning, presentation, and problem-solving skills.

5. Culture and Community Spirit

The program participants demonstrated a strong spirit of sharing and mutual support.

Through learning sessions, events, and community activities, I experienced a positive environment where participants were encouraged to ask questions, present ideas, and share their results.

This was an important factor that helped participants remain motivated throughout the internship.

What I Was Most Satisfied With

The aspect I was most satisfied with was the opportunity to directly explore and practice AWS services.

Instead of learning only through theory, I was able to develop a project, prepare workshop materials, and resolve practical issues during implementation.

Participating in events organized by FCAJ and the AWS Study Group also helped me gain additional knowledge, experience, and connections with people who share similar career interests.

Areas That Could Be Improved

In my opinion, the program could be improved in the following areas:

  • Organize additional periodic progress review sessions.
  • Provide several introductory workshops before participants begin their projects.
  • Offer more guidance on selecting an architecture that matches each participant’s current skill level.
  • Provide a clear checklist for each stage of the internship report.
  • Organize more teamwork or team-building activities.
  • Include additional sessions about career development and interview preparation.
  • Help participants review AWS costs to reduce the risk of unexpected charges.

Suggestions for Future Participants

For participants joining the program in the future, I suggest that they:

  • Create a learning plan at the beginning of the program.
  • Select a project that matches their knowledge and available time.
  • Complete individual components before expanding the architecture.
  • Regularly review the AWS resources they are using.
  • Record errors and their solutions for inclusion in the report.
  • Communicate with mentors when an issue takes too long to resolve.
  • Focus on building a working system instead of designing an architecture that is unnecessarily complex.

Recommendation of the Program

I would recommend the First Cloud AI Journey program to students who are interested in AWS, Cloud Computing, and related technologies.

The program is suitable for students who want to:

  • Become familiar with cloud environments.
  • Practice using AWS services.
  • Develop an individual project.
  • Improve their self-learning skills.
  • Participate in a technology community.
  • Explore career opportunities in the cloud computing field.

However, participants should be proactive, willing to study documentation, and prepared to spend time practicing regularly.

Future Expectations

In the future, I hope to continue participating in programs, workshops, and events organized by FCAJ or the AWS Study Group.

I would also like to have opportunities to:

  • Study AWS architecture in greater depth.
  • Participate in practical cloud projects.
  • Learn more about security, databases, and serverless systems.
  • Improve my programming and problem-solving skills.
  • Prepare for suitable AWS certifications.
  • Connect with and learn from the AWS community in Vietnam.

Acknowledgements

I sincerely thank the mentors, the First Cloud AI Journey organizing team, FCAJ, and the AWS Study Group for supporting me throughout the internship.

The knowledge, experience, and feedback that I received during the program will provide an important foundation for my continued learning, skill development, and future career path.
