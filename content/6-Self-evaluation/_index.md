During my internship at **Amazon Web Services Vietnam Co., Ltd.**, from **April 13, 2026** to **July 31, 2026**, I had the opportunity to learn about cloud computing, explore AWS services, and apply my knowledge to a practical project.

During the internship, I worked on the **CloudPay – Payment System on AWS** project. The objective of this project was to build a simple payment system that could deploy frontend applications, authenticate users, receive payment requests, and monitor the processing workflow on AWS.

Through this project, I learned about and used the following services:

- **Amazon S3** to host the Customer Web Application and Admin Dashboard.
- **Amazon CloudFront** to distribute frontend content.
- **Amazon Cognito** to manage user accounts and authentication.
- **Amazon API Gateway** to receive payment requests.
- **AWS Lambda** to process requests and generate transaction information.
- **Amazon CloudWatch** to review execution logs.
- **AWS Identity and Access Management (IAM)** to manage permissions between services.

In addition to technical knowledge, I improved my skills in researching documentation, developing workshop content, writing reports, managing tasks, and resolving issues during implementation.

Regarding my working attitude, I always tried to complete assigned tasks, proactively researched solutions when facing difficulties, and accepted feedback to improve my work. However, I recognize that I still need to improve my discipline, communication skills, and ability to analyze problems systematically.

### Achievements

After completing the internship, I achieved the following results:

- Gained a better understanding of fundamental cloud computing concepts.
- Learned how to deploy static websites using Amazon S3 and CloudFront.
- Learned how to create user accounts and sign-in functionality with Amazon Cognito.
- Learned how to build a simple API using API Gateway and Lambda.
- Learned how to review execution logs using Amazon CloudWatch.
- Completed the workshop content in both Vietnamese and English.
- Improved my technical documentation and presentation skills.
- Gained experience in resolving issues while running Hugo and developing the internship report website.

### Areas for Improvement

In addition to the achievements above, I recognize that I need to improve in the following areas:

- Improve discipline and comply more strictly with schedules and organizational regulations.
- Create clearer work plans before beginning a task.
- Improve analytical thinking and solve problems step by step.
- Review content and configurations carefully before deployment.
- Improve communication skills in both academic and professional environments.
- Communicate earlier when encountering difficulties instead of spending too much time resolving them independently.
- Continue learning about security, databases, and AWS system architecture.
- Improve programming skills to build a more complete system.

### Development Goals

In the future, I plan to continue studying and practicing the following topics:

- Learn how to protect APIs using Amazon Cognito and an API Gateway JWT Authorizer.

### Conclusion

The internship gave me practical knowledge of AWS, helped me better understand the process of building a system on a cloud platform, and allowed me to identify the skills that I still need to develop.

Although the CloudPay project currently remains a basic simulation, it provides an important foundation for me to continue learning, improve my technical knowledge, and develop more complex projects in the future.
