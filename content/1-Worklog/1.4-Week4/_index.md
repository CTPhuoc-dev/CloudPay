### Week 4 Objectives:

* Learn about AWS services related to security, monitoring, and automation.
* Become familiar with serverless and container-based architectures on AWS.
* Learn about automated application deployment through CI/CD.
* Understand basic methods for monitoring and optimizing AWS costs.
* Improve knowledge of building and operating systems in a cloud environment.

### Week 4 Results:

* Understood the importance of security when building and operating systems on AWS.
* Became familiar with several AWS security services and features:
  * IAM Permission Boundaries
  * AWS Key Management Service
  * AWS Security Hub
  * AWS Web Application Firewall
* Understood the role of Amazon CloudWatch in:
  * Collecting logs.
  * Monitoring metrics.
  * Reviewing resource status.
  * Supporting troubleshooting and error detection.
* Learned that Grafana can be used to visualize system monitoring data.
* Understood the basic concept of serverless computing and how AWS Lambda runs code without requiring direct server management.
* Became familiar with AWS Systems Manager and several resource management features.
* Understood the concepts of containers, Docker, and the role of Amazon ECS.
* Learned about the basic CI/CD workflow and the role of AWS CodePipeline in automating application deployment.
* Understood several AWS cost optimization methods:
  * Auto Scaling
  * Savings Plans
  * Reserved Instances
* Learned how to review cost information and active resources in an AWS account.
* Gained a general understanding of security, monitoring, automation, application deployment, and cost management on AWS.
